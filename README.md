# Zenn CLI

このリポジトリは[Zenn CLI](https://zenn.dev/zenn/articles/zenn-cli-guide)で管理されています。

## 利用可能なコマンド

### 新しい記事を作成する

```bash
npx zenn new:article
```

### 新しい本を作成する

```bash
npx zenn new:book
```

### 投稿をプレビューする

```bash
npx zenn preview
```

ブラウザで <http://localhost:8000> が開き、記事のプレビューを確認できます。
