## はじめに

GitHub Copilotと言えば、コード補完やチャット機能が有名ですが、実はそれ以外にも便利な機能がたくさんあります。

この記事では、**インライン質問**、**チャットのエージェント機能**、**プランモード**といった主要機能以外で、意外と知られていない便利な機能を紹介します。

:::message
この記事で紹介する機能は、GitHub Copilot（有料版）が必要です。
:::

## 1. コードレビュー機能

GitHub Copilotには、コードレビューを支援する機能があります。

### 使い方

1. VS Codeでファイルを開く
2. コマンドパレット（`Cmd+Shift+P` / `Ctrl+Shift+P`）を開く
3. `GitHub Copilot: Review and Comment` を選択

または、エディタ上で以下の操作も可能です：

- コードを選択して右クリック → `Copilot` → `Review and Comment`

### 何ができるか

- コードの問題点を指摘
- パフォーマンスの改善提案
- セキュリティ上の懸念の検出
- ベストプラクティスからの乖離を指摘

### 実例

```typescript
// レビュー前のコード
async function getUsers() {
  const response = await fetch('/api/users');
  return response.json();
}
```

このコードに対してCopilotがレビューすると：

- エラーハンドリングが不足している
- レスポンスのステータスコードをチェックすべき
- 型定義がない

といった指摘をしてくれます。

## 2. コミットメッセージ生成機能

変更内容から適切なコミットメッセージを自動生成してくれる機能です。

### 使い方

#### VS Code の場合

1. ソース管理タブを開く
2. コミットメッセージ入力欄の右側にある**スパークルアイコン（✨）**をクリック
3. 差分を分析して、自動的にコミットメッセージを生成

#### コマンドラインの場合

GitHub CLI拡張を使う方法もあります：

```bash
gh copilot suggest "変更内容を要約したコミットメッセージを生成"
```

### 生成されるメッセージの例

変更内容：
- `user.ts` にバリデーション追加
- `README.md` にインストール手順追加

生成されるメッセージ：
```
feat: ユーザーバリデーション追加とドキュメント更新

- user.tsにメールアドレスのバリデーションを追加
- READMEにインストール手順のセクションを追加
```

### Tips

- 生成されたメッセージは編集可能なので、必要に応じて調整しましょう
- Conventional Commits形式で生成されることが多いです

## 3. テストコード生成機能

既存のコードに対して、テストコードを自動生成できます。

### 使い方

1. テストしたい関数やクラスを選択
2. 右クリック → `Copilot` → `Generate Tests`

または、チャットで明示的に指示：
```
/tests この関数のテストを生成して
```

### 生成例

元のコード：
```typescript
export function calculateTotal(items: Item[]): number {
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0);
}
```

生成されるテスト：
```typescript
import { calculateTotal } from './cart';

describe('calculateTotal', () => {
  it('空の配列の場合は0を返す', () => {
    expect(calculateTotal([])).toBe(0);
  });

  it('単一アイテムの合計を正しく計算する', () => {
    const items = [{ price: 100, quantity: 2 }];
    expect(calculateTotal(items)).toBe(200);
  });

  it('複数アイテムの合計を正しく計算する', () => {
    const items = [
      { price: 100, quantity: 2 },
      { price: 50, quantity: 3 },
    ];
    expect(calculateTotal(items)).toBe(350);
  });
});
```

### ポイント

- プロジェクトで使用しているテストフレームワークを自動検出
- エッジケースも考慮したテストを生成
- 既存のテストファイルのスタイルに合わせて生成

## 4. ドキュメント生成機能（Docstring）

関数やクラスに対して、自動的にドキュメントコメントを生成します。

### 使い方

1. 関数やクラスの定義の上の行で `/doc` を入力
2. または、関数を選択して右クリック → `Copilot` → `Generate Docs`

### 生成例

元のコード：
```typescript
function processPayment(userId: string, amount: number, currency: string) {
  // 処理...
}
```

生成されるドキュメント：
```typescript
/**
 * ユーザーの支払いを処理します
 * 
 * @param userId - 支払いを行うユーザーのID
 * @param amount - 支払い金額
 * @param currency - 通貨コード（例：'JPY', 'USD'）
 * @returns 支払い処理の結果
 * @throws {PaymentError} 支払い処理に失敗した場合
 */
function processPayment(userId: string, amount: number, currency: string) {
  // 処理...
}
```

### 対応言語

- JavaScript/TypeScript: JSDoc形式
- Python: docstring形式
- Java: Javadoc形式
- その他の言語も各言語の標準的なドキュメント形式で生成

## 5. コマンドパレットのショートカット

VS Code上でCopilotの機能に素早くアクセスするためのショートカットです。

### 主要なコマンド

#### `Cmd/Ctrl + I`
- インラインチャットを開く
- 選択範囲に対して質問や編集指示が可能

#### `Cmd/Ctrl + Shift + I`
- サイドバーのCopilotチャットを開く
- より詳細な会話が可能

### その他の便利なコマンド

コマンドパレットから使える機能：

- `GitHub Copilot: Explain This` - コードの説明を生成
- `GitHub Copilot: Fix This` - バグの修正提案
- `GitHub Copilot: Generate Docs` - ドキュメント生成
- `GitHub Copilot: Generate Tests` - テスト生成

### キーバインドのカスタマイズ

`keybindings.json` でカスタマイズ可能：

```json
[
  {
    "key": "cmd+shift+r",
    "command": "github.copilot.reviewAndComment",
    "when": "editorTextFocus"
  }
]
```

## 6. ワークスペースコンテキスト機能

プロジェクト全体の構造を理解して、より適切な提案をしてくれる機能です。

### 使い方

チャットで `@workspace` を使用：

```
@workspace このプロジェクトの認証の仕組みを説明して
```

### 何ができるか

- プロジェクト内のファイルを横断的に検索
- 複数ファイルにまたがる実装パターンを理解
- プロジェクト固有の命名規則やアーキテクチャに沿った提案

### 実例

```
@workspace ユーザー登録の実装を参考に、商品登録の実装を作って
```

このように指示すると、既存の `UserController` の実装を参考にして、同じパターンで `ProductController` を生成してくれます。

### Tips

- `@workspace /new` で新しいファイル作成を支援
- `@workspace /explain` でプロジェクト構造の説明
- `@workspace /search <keyword>` でコードベース検索

## 7. Fix機能（エラー修正支援）

エラーやワーニングに対して、自動的に修正案を提案してくれます。

### 使い方

1. エディタ上でエラーや警告が表示されている箇所にカーソルを置く
2. 電球アイコン（💡）をクリック
3. `Fix using Copilot` を選択

または、エラー部分を選択して `Cmd/Ctrl + .` → `Fix using Copilot`

### 修正例

#### TypeScriptのエラー

エラー：
```typescript
const users: User[] = await fetchUsers();
// Error: Property 'map' does not exist on type 'Promise<User[]>'
const names = users.map(u => u.name);
```

修正案：
```typescript
const users: User[] = await fetchUsers();
const names = users.map(u => u.name);
// または
const names = (await fetchUsers()).map(u => u.name);
```

#### リンターの警告

警告：
```javascript
// ESLint: 'var' is not allowed. Use 'let' or 'const' instead
var count = 0;
```

修正案：
```javascript
let count = 0;
```

### ポイント

- 複数の修正案を提示してくれることもある
- プロジェクトの設定（ESLint、Prettierなど）を考慮した修正

## 8. スラッシュコマンド集

チャットで使える便利なスラッシュコマンドです。

### `/explain`
選択したコードの説明を生成

```
/explain このアルゴリズムの時間計算量は？
```

### `/fix`
バグや問題の修正案を提案

```
/fix この関数でメモリリークが発生している
```

### `/tests`
テストコードを生成

```
/tests カバレッジを上げるためのテストを追加
```

### `/simplify`
コードをシンプルにリファクタリング

```
/simplify この関数を読みやすくして
```

### `/optimize`
パフォーマンスの最適化提案

```
/optimize このループ処理を高速化して
```

### `/docs`
ドキュメントを生成

```
/docs このAPIの使い方を説明するREADMEを作成
```

### `/new`
新しいファイルやコンポーネントを作成

```
/new React Hooksを使ったカウンターコンポーネント
```

## 9. ターミナル統合機能

ターミナルでもCopilotの支援を受けられます。

### GitHub CLI拡張

```bash
# GitHub CLI拡張をインストール
gh extension install github/gh-copilot

# コマンドの提案を受ける
gh copilot suggest "すべての.logファイルを削除する方法"

# コマンドの説明を受ける
gh copilot explain "git rebase -i HEAD~3"
```

### VS Code統合ターミナル

VS Codeのターミナルでも支援が受けられます：

1. ターミナルでコマンドを入力開始
2. `Tab` キーで補完候補を表示
3. エラーメッセージをコピーして、Copilotに質問

```bash
# エラーが発生したら
npm install
# Error: EACCES: permission denied

# Copilotに聞く（チャット）
"このエラーの解決方法は？"
```

## 10. カスタム指示機能

プロジェクト固有のルールや好みを設定できます。

### 設定方法

1. `.github/copilot-instructions.md` ファイルを作成
2. プロジェクトのコーディング規約や好みを記述

### 設定例

```markdown
# Copilot Instructions

## コーディングスタイル
- 関数は必ずアロー関数で記述する
- コメントは日本語で書く
- エラーハンドリングは必ず実装する

## 命名規則
- コンポーネント名はPascalCase
- 関数名・変数名はcamelCase
- 定数はUPPER_SNAKE_CASE

## アーキテクチャ
- ビジネスロジックはservicesディレクトリに配置
- データアクセスはrepositoriesディレクトリに配置
```

### 効果

Copilotが提案するコードが、プロジェクトの規約に沿ったものになります。

## 11. エディタ連携機能

### インライン編集

コードの特定部分を選択して、その場で編集指示ができます。

```typescript
// 選択して Cmd/Ctrl + I
function calculatePrice(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}

// 指示: "型を追加して"
// 結果:
function calculatePrice(items: Item[]): number {
  return items.reduce((sum, item) => sum + item.price, 0);
}
```

### マルチファイル編集

複数ファイルにまたがる変更も一度に提案してくれます。

```
@workspace ユーザー登録機能を追加して（フロントエンド、バックエンド、データベーススキーマすべて）
```

## 12. 言語・フレームワーク固有の機能

### React
- コンポーネントの型定義自動生成
- Hooksの最適な使い方を提案
- パフォーマンス最適化（useMemo、useCallbackの提案）

### Python
- Type Hintsの自動追加
- Pythonic なコードへのリファクタリング
- データクラスの生成

### SQL
- クエリの最適化提案
- インデックスの追加提案
- セキュリティ上の問題（SQLインジェクション）の指摘

## 活用のコツ

### 1. 具体的に指示する

❌ 悪い例：
```
この関数を改善して
```

✅ 良い例：
```
この関数にエラーハンドリングを追加して、型定義も充実させて
```

### 2. コンテキストを提供する

```
このプロジェクトではPrismaを使っています。
ユーザー登録のリポジトリパターンを実装して
```

### 3. 段階的に進める

一度にすべてを生成するのではなく、小さな単位で確認しながら進めましょう。

### 4. 生成されたコードは必ずレビューする

Copilotは便利ですが、完璧ではありません。セキュリティやパフォーマンスの観点で必ずレビューしましょう。

## まとめ

GitHub Copilotには、コード補完やチャット以外にも多くの便利な機能があります：

- コードレビュー・テスト生成で品質向上
- コミットメッセージ・ドキュメント生成で作業効率化
- ワークスペースコンテキストでプロジェクト全体を理解
- Fix機能でエラー解決を支援
- カスタム指示でプロジェクトに最適化

これらの機能を使いこなすことで、開発効率が大幅に向上します。ぜひ試してみてください！
